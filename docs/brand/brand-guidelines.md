## 🧩 Style visuel (UI / UX)

| Élément | Spécification |
| :--- | :--- |
| **Bords arrondis** | `12px` (cartes, boutons, modales, champs de saisie) |
| **Ombres** | `box-shadow: 0 4px 12px rgba(13, 34, 66, 0.08)` — Légères, subtiles, pas trop marquées |
| **Espacement** | Aéré, beaucoup de padding (ex: 24px entre les sections). Pas de sensation de tassement. |
| **Animations / Transitions** | `0.3s ease` sur les hover, les changements d'état, les ouvertures de modales. Pas d'effets excessifs. |
| **Boutons — généraux** | Bords arrondis `12px`, padding vertical `12px`, padding horizontal `24px`. |
| **Boutons — chronométrage (mobile)** | Trois boutons signature : |
| | **Démarrer** : Vert (`#2E7D32`) — icône play |
| | **Pause** : Violet (`#7B1FA2`) — icône pause |
| | **Arrêter** : Rouge (`#D32F2F`) — icône stop |
| | Taille : grands, faciles à taper au volant (min 48px de hauteur). |
| **Badges / Tags** | Arrondis `16px`, padding `4px 12px`. Couleurs selon le statut (vert, orange, rouge). |
| **Feuillet quotidien (PDF / écran)** | Reprend la grille A/B/C/D du livret papier original. Fonds alternés pour faciliter la lecture. |

## 📱 Composants spécifiques (par rôle)

### Salarié (mobile)
- Écran d'accueil : 3 gros boutons (Démarrer / Pause / Arrêter)
- Timeline segmentée A/B/C/D en temps réel
- Alerte de dépassement : bannière rouge avec icône d'avertissement
- Feuillet quotidien généré : reprend la mise en page du livret papier

### Employeur (web / desktop)
- Tableau de bord : KPI en haut (conformité globale, alertes, risques)
- Liste des salariés groupée par statut (Non conforme / À surveiller / Conforme)
- Filtres : par véhicule, période, statut documentaire
- Générateur de rapports : sélecteur de période (1 jour, 7 jours, 1 mois, 1 an, 5 ans, personnalisé)

## 📌 RAPPEL — Inspire-toi du livret papier original

L'identité visuelle de START2WAY est un hommage assumé au Livret Individuel de Contrôle papier. Le navy profond et l'amber doré sont directement inspirés des teintes du carnet original. Les trois boutons (Vert / Violet / Rouge) reprennent le code couleur des actions métier.

** L'objectif n'est pas de faire "vieux" mais de faire "officiel" et "fiable".

** Le produit est un système de preuve, pas un gadget.
