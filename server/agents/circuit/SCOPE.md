L'agent est autorisé à :
identifier recipient probable
identifier address probable
détecter ligne vide
détecter adresse incomplète
détecter doublon probable
détecter incohérence ville/CP
détecter parsing ambigu
proposer une séparation recipient/address
signaler géocodage douteux
signaler ordre optimisé suspect
expliquer les problèmes au chauffeur

inventer une adresse
modifier silencieusement une adresse
inventer coordonnées
inventer Place ID
inventer distance
inventer ETA
inventer client
supprimer une destination sans validation
changer l'ordre final après optimisation sans validation
